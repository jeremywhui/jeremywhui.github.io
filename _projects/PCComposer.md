Designed and managed a full stack web application using a React.js frontend and SQLite3 backend database to generate/purchase a PC build using an AI chatbot from 100+ computer parts. Used AWS S3, applied design patterns, and enforced object-oriented system specifications according to business goals/use cases in order to effectively coordinate an 8-member team. Applied an Agile development methodology.
