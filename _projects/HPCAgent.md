With the increasing demand for using CC to protect DNNs used by research scientists, there is need for the development of an agent that is able to automate the deployment of CoCo and detect policy-violating workloads. We outline the current work that has been done so far towards creating such an agent, which involves first selecting a processor capable of creating VM-based TEEs. We also show how CoCo can be set up in order to run any Docker image in an encrypted manner. We then outline the architecture of CoCo, the necessary components that the agent will manage, and how the agent will interact with the existing CoCo architecture. We will show the necessary machine learning concepts that will be utilized by the agent, what previous analysis techniques have been employed to detect malicious works, and how the agent may work to prevent the execution of malware. Finally, we detail the physical implementation and theoretical conceptual limitations of how such an agent may work.
