Developed a shoe shopping website with a SQL backend with various services depending on the user's role. Users are able to create auctions and post items for sale, bid for items, and a winner is declared at the end of an auction. Users are also able to browse and search for various items, set preferences for items they are interested in, and post questions. Admin and customer representatives are able to create accounts, generate sales reports, and answer questions posted by users. All create, read, update, and delete operations are handled in the SQL database.
