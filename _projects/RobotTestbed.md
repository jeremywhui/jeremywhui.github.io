Implemented an experimentation platform about human interactivity with indoor spaces using Python and Linux, and effectively communicated results in 5-minute weekly presentations. Set up 25 Raspberry Pis to securely communicate environment data to be processed in Flask database by an LLM. Implemented Precision Time Protocol (PTP) to synchronize clocks on a nanosecond scale.
